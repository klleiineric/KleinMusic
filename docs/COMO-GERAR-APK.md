# Como gerar o APK com o GitHub Actions

1. Crie uma conta em github.com e um repositório chamado KleinMusic.
2. Envie o projeto (veja o passo a passo no chat; o método mais confiável no celular é o Termux).
3. Cada envio para a branch main roda o fluxo "Gerar APK" sozinho (5 a 10 minutos).
4. Em Releases, abra o build mais recente e baixe KleinMusic-debug.apk.
5. Instale no celular (permita "instalar apps desconhecidos" para o navegador).
6. Se o fluxo falhar (vermelho): abra a execução, entre no passo que falhou e copie o erro.
